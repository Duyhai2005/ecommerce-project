# Ecommerce Project

Scaffold du an ecommerce gom frontend, backend, database va tai lieu.

## Cau truc

```text
ecommerce-project/
├─ frontend/
├─ backend/
├─ database/
├─ docs/
├─ .env.example
├─ .gitignore
├─ README.md
└─ docker-compose.yml
```

## Huong dan tiep theo

1. Chon framework frontend, vi du React, Vue, Next.js.
2. Chon framework backend, vi du Express, NestJS, Laravel, Spring Boot.
3. Cau hinh bien moi truong dua tren `.env.example`.
4. Thiet ke database trong `database/schema.sql`.
